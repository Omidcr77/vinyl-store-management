# Customer sales deck

- `flooring-vinyl-store-manager.pptx` is the editable seven-slide PowerPoint.
- `flooring-vinyl-store-manager.pdf` is the matching shareable handout.
- `flooring-vinyl-store-manager.html` is the print source for the PDF.
- `assets/` contains the app screenshots embedded in both formats.
- `build_deck.py` rebuilds the deck from screenshots in the project's `test-results/` folder.

Before sending it to a prospect, replace the closing slide's **Your name • Phone / WhatsApp • Email** line with your contact details. The screenshots come from the app's UI workflows and use sample/test records.
