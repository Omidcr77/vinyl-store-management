# Customer sales deck

- `flooring-vinyl-store-manager.pptx` is the editable seven-slide PowerPoint.
- `flooring-vinyl-store-manager.pdf` is the matching shareable handout.
- `flooring-vinyl-store-manager.html` is the print source for the PDF.
- `assets/` contains the Dari app screenshots and the font files used by the PDF.
- `build_deck.py` rebuilds the deck from screenshots in the project's `test-results/` folder.

The slides and screenshot examples are localized for Afghan Dari. Before sharing, replace the final slide's contact placeholders with your own name, phone/WhatsApp number and email. Screenshots use generated sample records.
